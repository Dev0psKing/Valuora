# Valuation Methodology

The platform will use multiple valuation approaches.

The primary valuation categories are:

1. Market Approach.
2. Income Approach.
3. Asset Approach.

---

## 1. Revenue Multiple Valuation

The revenue multiple method estimates enterprise value based on business revenue.

### Formula

```
Enterprise Value = Revenue × Revenue Multiple
```

### Example

Revenue: ₦100M

Industry Multiple: 0.8×

Enterprise Value: ₦80M

The multiple may be adjusted based on:

* Growth.
* Profitability.
* Recurring revenue.
* Customer concentration.
* Business risk.
* Industry.
* Geography.

---

## 2. EBITDA Multiple Valuation

The EBITDA multiple method estimates business value based on earnings.

### Formula

```
Enterprise Value = Adjusted EBITDA × EBITDA Multiple
```

### Example

Adjusted EBITDA: ₦20M

Industry Multiple: 3.5×

Enterprise Value: ₦70M

This method may be particularly suitable for established and profitable SMEs.

---

## 3. Multiple Adjustment Mathematics

Industry multiples should not remain static.

The platform should eventually calculate adjusted multiples.

### Conceptual Formula

```
Adjusted Multiple = Base Industry Multiple
                    × Growth Adjustment
                    × Revenue Quality Adjustment
                    × Operational Maturity Adjustment
                    − Risk Adjustment
```

### Example

Base Industry Multiple: 3.0×

Growth Adjustment: +0.2×

Recurring Revenue: +0.1×

Customer Concentration: −0.2×

Owner Dependency: −0.1×

```
Adjusted Multiple = 3.0 + 0.2 + 0.1 − 0.2 − 0.1 = 3.0×
```

Adjustment rules must eventually be supported by research, historical data, and professional valuation methodology.

---

## 4. Asset-Based Valuation

Asset-based valuation is important for asset-heavy businesses.

Examples include:

* Manufacturing.
* Logistics.
* Agriculture.
* Construction.

### Formula

```
Net Asset Value = Fair Market Value of Assets − Total Liabilities
```

Assets may include:

* Property.
* Equipment.
* Machinery.
* Vehicles.
* Inventory.
* Cash.
* Receivables.

Liabilities may include:

* Loans.
* Accounts payable.
* Outstanding obligations.

---

## 5. Enterprise Value and Equity Value

The platform must distinguish between enterprise value and equity value.

### Enterprise Value

Represents the total economic value of the business.

### Equity Value

Represents the value attributable to shareholders or owners.

### Simplified Formula

```
Equity Value = Enterprise Value − Total Debt + Cash
```

### Example

Enterprise Value: ₦100M

Debt: ₦20M

Cash: ₦10M

```
Equity Value = 100M − 20M + 10M = ₦90M
```

This distinction must be clearly presented to users.
